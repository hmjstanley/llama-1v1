# llama-1v1
A 2D two player game developed using Python and Pygame
## Gameplay
Control the llamas and spit at the other player, first one to lose all health loses!

## How to Run
### Prerequisites
Before running the game, make sure you have:
- **Python 3** installed on your computer.
- **Pygame** installed (used for graphics, input handling, and game mechanics).

### Installation
**1. Clone the repository**
Open
```bash
git  a terminal and run:clone https://github.com/hmjstanley/llama-1v1.git
```
**2. Navigate to the project directory**
```bash
cd llama-1v1
```
**3. Install the required dependencies**
```bash
python -m pip install pygame
```
Alternatively, if a `requirements.txt` file is provided:
```bash
python -m pip install -r requirements.txt
```
**4. Run the game**
```bash
python llamagame.py
```
The game should launch in a new window, ready to play!
